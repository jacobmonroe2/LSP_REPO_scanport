# Question 2 Design Explanation

The Template Method pattern is applied through the abstract `Report` class. `generateReport()` is the template method and is marked `final` so no subclass can change the order of steps. It calls `loadData()` then `formatHeader()` then `formatBody()` then `formatFooter()` in that fixed sequence. All four methods are abstract so each subclass is required to implement them. `StudentReport` and `CourseReport` each provide their own versions of those four methods with their own data and output but neither one can touch the overall workflow. In the `Driver` both report types are stored in a `List<Report>` and `generateReport()` is called on each one. This demonstrates polymorphism because the same method call produces different output depending on which subclass is actually running.
